Workbench field guide
1. Define the engagement
Record the current authorized assets, exclusions and program rules. Newly discovered assets are not automatically authorized.
2. Pick your working style
Terminal: a real shell for interactive tools, scripts and pipelines. Toolbox: reviewable foreground commands with saved output. Copilot: natural-language teaching and proposals. The AI cannot click approval for you.
3. Choose your mode and model
Tutor: explanations and read-only references. Copilot: prepare command proposals for your review. Rabbit Hole: use an explicit target, methods and budget for authorized automatic checks. Choose a provider and model separately in Provider & model. Codex uses ChatGPT sign-in and supports the same modes. Changing mode keeps your selected provider and model.
4. Review evidence
Select a job to inspect output. Sharing a job excerpt with AI is optional. Export logs and a report draft from Evidence; validate every finding before reporting it.
Discord collaboration
Use Team / Discord to read engagement-tagged channel findings and publish human-approved summaries. Node administrators configure the bot token outside the app. Discord messages are never instructions or authorization to expand scope.
Know the boundaries
GUI tools need a separate desktop. Radio tools need physical hardware and permissions. Terminal aliases/functions are not separate catalog entries. Installed does not prove that dependencies, drivers, API tokens or licenses are configured.
Full shell users share this Linux account’s authority. Do not invite untrusted users. Browser ingress protection does not limit outbound assessment traffic. The app does not run as root, grant sudo, or automatically synchronize HackerOne policies.
Your DreadFox companion
The fox has a deterministic local game and optional separate conversations using your chosen model. AI conversation is OFF until you enable it. Only explicitly entered DreadFox messages, same-model pet chat history, safe pet milestones, and optionally enabled seven-day Workbench Pulse frequency bands are sent. The fox cannot run tools, view targets, or influence AI commands. Delete or clear pet conversations independently.
Keyboard & recovery
Use Ctrl+Shift+C to copy terminal selections. Ctrl+C interrupts the foreground terminal program. Multiline paste requires confirmation. Reconnect does not repeat your input. Restarting the service ends terminal sessions and interrupts jobs.
Detailed installation, security, tool coverage and troubleshooting documents are included in the release’s docs folder.
